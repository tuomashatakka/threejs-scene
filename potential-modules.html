how to read this catalog

included means the current package already owns the capability. port means the source API is already a clean library-shaped candidate. adapt means the behavior is reusable but its host or ui coupling should be removed. keep app marks a useful reference implementation that should probably remain outside the package. experimental is a separate entry point or later decision.

an exact-name overlap is lexical evidence only. it does not prove that two implementations have behavioral parity, and identical webgl/webgpu factory names intentionally remain separate candidates.

props, materials, and authoring surfaces

named content deserves its own inventory: these are user-facing vocabulary, not just implementation helpers.

direct or alias overlap exists for rock, boat, deadTree → dead-tree, and lamp → lamp-post; the other variants add distinct silhouettes or placement semantics.

wasteland kit · included

the sixteen named kit geometries from meshes/packages/wasteland are already represented by KIT_PROP_NAMES. keep the wasteland scene modules as integration recipes rather than duplicate factories.

current material presets · included

metal, chrome, gold, plastic, rubber, matte, emissive, glass, plus toon, procedural matcap, holographic, triplanar, and the shared low-poly kit material.

surface-aware prop batching · adapt

playworld splits each prop into body, glow, and shiny surfaces, merges per surface, bakes vertex color plus contact occlusion, and instances each result. this is a reusable batching contract rather than three more material presets.

procedural textures · included

createGridTexture, createNoiseTexture, createGradientTexture, createSeamlessNoiseTexture, createMatcapTexture. remaining candidates are a generic cache/factory wrapper and createGradientToonMap compatibility.

mesh preview looks · keep app

wireframe, solid vertex-color, and iridescent physical-glass modes are excellent authoring previews. package only their reusable material factory if another consumer appears.

model-facing authoring · included + extend

the package already validates, builds, reviews, retries, and exposes schema for json prop specs. playworld adds whole-world normalization and scene mutation commands; meshes adds destructive geometry editing and undo snapshots.
